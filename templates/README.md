# Vorlagen

- [`AGENTS.project.md`](AGENTS.project.md) ist die kurze Anbindung eines Symcon-Repositories an diese zentrale Entwicklungsbasis.
- [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) hält Zweck, Architektur, Verträge, Abhängigkeiten und Prüfeinstiege eines Projekts kompakt fest.
- [`MODULE_README.md`](MODULE_README.md) ist das Grundgerüst für die verpflichtende README eines Moduls.
- [`REPO_README.md`](REPO_README.md) ist die Benutzerübersicht einer Modulbibliothek; beide README-Vorlagen enthalten keine Fehlerdiagnose oder Entwicklungshinweise.
- [`CHANGELOG.md`](CHANGELOG.md) ist die Vorlage für sichtbare Änderungen und die Versionshistorie einer Modulbibliothek.
- [`NEW_MODULE_PROJECT.md`](NEW_MODULE_PROJECT.md) ist die Entscheidungs- und Vollständigkeitscheckliste für ein neues Modulprojekt.

Vorlagen werden beim Übernehmen an das Zielprojekt angepasst. Platzhalter und nicht relevante Abschnitte bleiben nicht unbegründet stehen.
