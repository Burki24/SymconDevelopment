# Prinzipien

Prinzipien erklären, warum die Burki24-Symcon-Entwicklung bestimmte Entscheidungen bevorzugt. Konkrete Handlungsregeln stehen unter `standards/`; langfristige Einzelentscheidungen stehen unter `adr/`.

## Inhalt

- [`ENGINEERING.md`](ENGINEERING.md): technische und organisatorische Leitlinien
- [`AI_COLLABORATION.md`](AI_COLLABORATION.md): Zusammenarbeit mit Coding-Agenten

Prinzipien ändern sich seltener als Standards. Eine Änderung muss deshalb auf ihre Auswirkungen auf `AGENTS.md`, Standards, Vorlagen und bestehende ADRs geprüft werden.
