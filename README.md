# SymconDevelopment

SymconDevelopment ist die schlanke, zentrale Entwicklungsbasis für Burki24-Symcon-Projekte.

Das Repository bündelt gemeinsame Arbeitsregeln, Qualitätsstandards, Entscheidungsvorlagen und wiederverwendbares Wissen, ohne die einzelnen Modul-Repositories mit kopierten Regelwerken zu belasten.

Die Basis ist von guten Ideen aus SAEF inspiriert, bleibt aber bewusst auf die bestehende Burki24-Infrastruktur zugeschnitten. SAEF-spezifische Deployment-, Runtime-Mirror-, SSH-/PowerShell- oder MQTT-Frameworkteile sind nicht Bestandteil dieses Repositories.
